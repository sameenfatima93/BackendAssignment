## 📋 Question Summaries & Methods Applied

### **Question 1: Online Store Sales Report** (`q1.js`)
- `find()` with arrow function to identify the first order greater than 2000.
- `filter()` to retrieve all orders over 1000.
- `reduce()` to sum total daily sales.

### **Question 2: Student Performance Analyzer** (`q2.js`)
- `map()` to create a new list with practice assessment marks (+5).
- `filter()` for scores 70 or above.
- `find()` for the first score > 90.
- `reduce()` for total score calculation without altering original data.

### **Question 3: Employee Data from an API** (`q3.js`)
- `filter()` to separate IT department staff.
- `find()` to retrieve the first high-salary employee (> 90000).
- `map()` to extract employee names.
- `reduce()` to aggregate total company salary.

### **Question 4: Store Inventory Using JavaScript Map** (`q4.js`)
- `new Map()` initialization and manipulation (`set()`, `get()`, `has()`, `delete()`, `clear()`).
- Iteration using `forEach()`.
- Checking keys, values, and total entries count (`size`).

### **Question 5: Student Result Object** (`q5.js`)
- JavaScript Object literal creation with property access (dot and bracket notation).
- Methods using `this` to calculate total marks and score percentage.
- Deleting properties using the `delete` operator.
